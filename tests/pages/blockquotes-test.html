Blockquote – Component test

This page tests .zh-blockquote layout, icon sizing, responsive clamp typography, optional attribution (with/without avatar), and spacing tokens.

What to check:
• The blockquote container respects max-width: 1100px and uses transparent background / no borders.
• Inner layout uses a 2-column grid: large quote mark icon on the left, quote text on the right.
• The quote mark and quote text scale smoothly with clamp() as the viewport changes.
• Attribution grid aligns avatar + byline neatly, and still looks correct when the avatar is omitted.

Width guide container (test helper): the component itself should cap at 1100px even if this page is wider. Resize the preview to see the clamped text sizes.

Baseline rendering test: verifies the core grid layout (icon column + text column) plus attribution layout with an avatar.
