Images – Component test

This page tests .image, .image__img (block, 100% width/height, object-fit: cover), .image__caption, and aspect-ratio modifiers: .image-16x9, .image-1x1, .image-2x3, .image-5x3.

What to check:
• Each image container maintains its aspect ratio while the image fills it using object-fit: cover.
• Image should crop (not stretch) when the container ratio differs from the source image.
• Caption spacing and color match the component rules.
• The figure should never exceed its container width (max-width: 100%).

16×9 (image-16x9)

Aspect-ratio test for a 16:9 container using a source image with a different ratio to confirm cropping (not stretching).

1×1 (image-1x1)

Square crop test to verify that a wide source image is cropped into a 1:1 container without distortion.

2×3 (image-2x3)

Portrait ratio test to confirm tall containers behave correctly and the image still fills/crops properly.

5×3 (image-5x3)

Wide ratio test using a square source to confirm the component crops a square image into a wider container and preserves caption styling.

Responsive width check

Layout constraint test ensuring the component never exceeds its container width and scales down cleanly on smaller viewports.

Resize the viewport narrower: each .image should remain within the container (max-width: 100%). The image should always fill its box (width:100%; height:100%) and crop via object-fit: cover.
