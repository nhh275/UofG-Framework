Calendar – Component test

This page tests .zh-calendar, month pagination, weekday row, month title, day grid, weekend styling, today styling, hover/focus-visible states, and event markers.

How to test:
• Click month buttons to switch between sample months.
• Hover day cells: the date number should underline.
• Use Tab to focus month buttons and day buttons to verify focus-visible outlines.
• Confirm weekend labels/dates are lighter, today is a blue circle, and empty cells stay visually blank.
• Event markers should appear as small grey dots under selected dates.

Edge checks

Weekend styling:
Saturday and Sunday weekday labels should be lighter, and weekend dates in the table should also appear lighter unless marked as today.
Empty cells:
Leading/trailing cells in shorter months should remain visually blank because .zh-calendar__cell--empty makes text transparent.
Today styling:
The current test month includes a fixed “today” date so the blue circular highlight can be verified reliably.
Accessibility:
Day cells are buttons so they can receive keyboard focus. Use Tab to confirm the 4px yellow focus outline appears.
