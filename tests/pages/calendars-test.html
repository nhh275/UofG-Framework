Calendar – Component test

This page tests the calendar component rendered by calendars.js, including month pagination, weekday row, month label, day grid, today highlight, and event markers.

How to test:
• Click month buttons to switch months.
• Hover day cells to confirm date underline appears.
• Use Tab to focus month buttons and day buttons and check focus styling.
• Confirm event markers render for the days listed in data-events.
• Confirm the current day is highlighted only when the rendered month matches the real current month.

Default calendar

Baseline component test using the external JavaScript file to render the internal calendar structure.

Expected: the calendar renders month buttons from Jan–Dec, weekday labels, a month name, and a table of day buttons. Event dots should appear on days 4, 12, 17, and 26 in whichever month is currently shown.

Edge checks

Use this checklist while interacting with the rendered calendar.

Expected:
• Weekend labels (Sat/Sun) should appear lighter than weekdays.
• Empty cells at the start/end of shorter months should remain visually blank.
• The active month button should use the is-active styling.
• The calendar should remain contained within the demo width and not overflow horizontally.
