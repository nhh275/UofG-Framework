Profile Card – Component test

This page tests .zh-profile-card, image sizing and circle crop, spacing, text hierarchy, and link styling for email and profile links.

How to test:
• The card should size to its content because it uses display: inline-block and width: auto.
• The profile image should render as a 250×250 circular crop.
• Name, title, email, location, and profile link should show the expected spacing and hierarchy.
• Email and profile links should be blue and underlined.
