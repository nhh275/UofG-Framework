Radio – Component test

This page tests the .radio group layout, option styling, checked state dot (:checked + .radio-control::after), focus-visible ring color (:focus-visible + .radio-control), disabled styling (via :has(input:disabled)), and error visibility (.radio-error-visible).

How to test:
• Click each option: only one should be checked per group.
• Use Tab to focus the radio (not the label). Expected: border becomes --highlight on focus-visible.
• Disabled option: cursor not-allowed, muted text, muted ring and dot.
• Error group: add/remove radio-error-visible class to show/hide the error message.
