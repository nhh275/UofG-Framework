Pagination – Component test

This page tests .pagination layout, link spacing, active state underline, centered alignment, and disabled/ellipsis behavior.

How to test:
• Links should be centered as a horizontal row.
• Active page should show a dark underline via ::after.
• Disabled items (using inline pointer-events: none) should appear faded and not clickable.
• All links should remain keyboard-focusable unless explicitly disabled.
