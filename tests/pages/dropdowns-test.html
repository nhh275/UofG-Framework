Dropdown – Component test

This page tests .dropdown default, error, and disabled states; label/hint/error spacing; select hover/focus/active; and the arrow pseudo-element on .dropdown__control::after.

How to test:
• Hover the select: border + background should change.
• Click/focus (Tab): outline should appear with offset.
• Active (mouse down): border becomes highlight.
• Error state: error text shows and select border + arrow become red.
• Disabled: select is not interactive and arrow becomes muted (via .dropdown--disabled).
• Spacing: stacked dropdowns should get margin via .dropdown + .dropdown.
