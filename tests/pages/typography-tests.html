Text alignment

Aligns text to the start edge (left in LTR, right RTL)

.text-start This text should align start.

Centres text horizontally

.text-center This text should be centered.

Aligns text to the end edge (right in LTR, left in RTL)

.text-end This text should align end.

Spreads text to align both left and right edges by adjusting word spacing

.text-justify Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.

Demostrates alignment changing at breakpoints: start → centre → end → justify as the viewpoint gets wider

Wrap / nowrap / break / truncate

Allows text to wrap onto multiple lines (normal wrapping behaviour)

.text-wrap
ThisIsAReallyReallyReallyLongWordThatShouldWrapNormallyIfAllowed (depends on browser rules)

Prevents wrapping; text stays on one line and will overflow

.text-nowrap
This is a long sentence that should stay on ONE line and overflow the box.

Forces long words/string to break to avoid overflow

.text-break
ThisIsAReallyReallyReallyLongWordThatShouldBreakInTheMiddleToAvoidOverflow

Turncates overflow text and shows an slipsis (typically requires overflow: hidden and white-space: nowrap)

.text-truncate-ellipsis This line is too long so it should truncate with an ellipsis at the end.
