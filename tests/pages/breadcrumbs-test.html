Breadcrumb – Component test

This page tests .zh-breadcrumb layout, separators (›), link hover/focus states, wrapping, and current-page behavior using aria-current="page".

How to test:
• Confirm the separator appears only between items (.item + .item::before).
• Hover links: underline appears.
• Tab to focus links: outline + border-radius appear, underline removed while focused.
• Current page item: greyed out and not clickable (pointer-events disabled).
