Table – Component test

This page tests base table styles for .table and .zh-table, including headers, rows, numeric alignment, borders, and footer styles.

How to test:
• Verify borders between rows and columns.
• Confirm header cells use heavier font weight.
• Check numeric columns align right and use tabular numbers.
• Ensure the final row removes its bottom border.
• Confirm footer styling (top border + right-aligned totals).
