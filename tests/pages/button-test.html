Buttons – Component test

This page tests .btn base styles and variants: .btn-primary, .btn-secondary, .btn-outline, including hover, focus, and disabled states.

How to test:
• Hover each enabled button to verify hover colors.
• Use Tab to focus buttons and verify the highlight outline appears on focus.
• Confirm disabled buttons show the correct colors and a not-allowed cursor, and are not clickable.

Primary buttons

Tests the primary button variant styling and interaction states.

Expected: hover swaps background/text; focus shows outline using --highlight.

Secondary buttons

Tests the secondary button variant and verifies it uses its own hover/background rules distinct from primary.

Expected: hover background becomes --lgrey1; focus shows highlight outline.

Outline buttons

Tests the outline-only button variant where the border is the primary affordance.

Expected: outline style is visible; hover changes text color; focus shows highlight outline.
