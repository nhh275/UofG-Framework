Text Blocks – Component test

This page tests .zh-text-block grid layout, border/padding, heading styles, content spacing (> * + *), responsive single-column mode (≤768px), image sizing, and link focus outline.

How to test:
• Desktop: two-column grid (heading column min 180px/max 320px) with column gap --space10.
• Mobile (≤768px): switches to one column with row gap --space-3.
• Content spacing: each block element after the first gets top margin --space3.
• Links: underline + blue, and show focus outline on Tab.
