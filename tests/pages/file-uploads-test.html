File Upload – Component test

This page tests .zh-file-upload, label spacing, hidden input behavior, button hover/focus/active states, and filename display.

How to test:
• Click the upload button to choose a file.
• After selection, the filename text should update.
• Hover the button: background and border styling should change.
• Tab to the button and press Enter/Space: focus styling should appear and the file picker should open.
• Long filenames should stay on one line because white-space: nowrap is applied.
