Breakout – Component test

This page tests .breakout, .breakout__content, and the modifier variants .breakout--inset and .breakout--warning, including pseudo-elements, padding, borders, and spacing.

How to test:
• Default breakout: light grey background with left-heavy padding from --space11.
• Inset breakout: vertical grey inset bar appears using ::before.
• Warning breakout: top/bottom borders appear and a circular exclamation icon appears using ::after.
• Check vertical spacing between breakouts comes from margin: --space6 0.

Default breakout

Baseline test of spacing, background, and content flow without any modifier.

This is a standard breakout block. It should have a light grey background, generous left padding, and no decorative bar or icon.

Expected: no pseudo-element visible. Padding should still indent content noticeably from the left.

Inset breakout

Tests the left inset bar created with .breakout--inset::before.

This inset variant should show a vertical bar on the left, positioned inside the container with top and bottom offsets from --space3.

Expected: a 4px grey vertical bar appears at left: --space8.

Warning breakout

Tests warning styling, including extra left padding, top/bottom borders, and circular exclamation mark.

This warning breakout should display an exclamation icon in a bordered circle, plus top and bottom borders. The text content should start further right than the default breakout.

Expected: warning icon appears via ::after at left: --space8, with extra padding-left from --space12.

Edge case: longer content

Stress test for wrapping and vertical spacing with a longer block of text.

This is a much longer breakout message intended to test how multiline content wraps inside the component while maintaining the warning icon position and the left padding. The icon should remain visually aligned near the top of the breakout and the content should not overlap it.

A second paragraph verifies that normal flow content still behaves correctly inside the breakout container.

Expected: paragraphs wrap naturally, icon stays fixed in its absolute position, and content remains clear of the icon area.
