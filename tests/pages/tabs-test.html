Tabs – Component test

This page tests .tabs, .tabs__list, .tabs__tab, active/hover/focus states, underline styling, and panel spacing via .tabs__panel.

How to test:
• Hover tabs → text darkens and grey underline appears.
• Active tab → blue text + bold + blue underline.
• Focus tabs using Tab → highlight outline appears.
• Panels change when a different tab is activated (test harness JS).
