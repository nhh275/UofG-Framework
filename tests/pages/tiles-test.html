Tiles – Component test

This page tests the .tiles-container grid layout, tile spacing, top/bottom borders, image aspect ratio, and text flow inside tiles.

How to test:
• Resize the viewport: tiles should auto-fit and wrap based on minmax(260px, 1fr).
• Check vertical spacing: each tile starts lower via margin-top.
• Confirm top and bottom borders use the --rust colour.
• Images maintain a 16:9 ratio and never overflow their container.
