Form field + Typography – Component test

This page tests: spacing tokens, colour tokens (for required/error/focus), primary/secondary typography classes, and the .zh-form-field input + textarea styles (default/hover/focus/error/disabled).

How to test:
• Hover inputs → border becomes --mgrey1.
• Focus (Tab/click) → outline uses --highlight, border becomes --dgrey3.
• Error modifier → border becomes --error and remains error-coloured on focus.
• Disabled → greyed background and not-allowed cursor.
• Required asterisk → should be blue (--uni-blue).
